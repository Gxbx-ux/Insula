To play the game you have to download Visual Code Studio(the Best way) and download the .NET SDK.
To start the game, you have to clock on "Terminal" and click on "New Terminal" and write "dotnet run --project.\Insula-v9\JogoDasIlhas.csproj" and enter.
ATTENCTION:
You only have to write "dotnet run --project.\Insula-v9\JogoDasIlhas.csproj" if is the first time with the code, if you write that, play, and close the game, you just have to write "dotnet run"
